# 🚀 Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites

Make sure you have Node.js and npm installed:
- **Node.js** (v18 or higher recommended)
- **npm** (comes with Node.js)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd Cosmos-Landing-Page
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open the local address provided by Vite (usually `http://localhost:5173`) in your browser.

---

## 📦 Production & Deployment

To compile the application into static files optimized for production:

```bash
npm run build
```

To preview the generated production build locally:

```bash
npm run preview
```

The production bundle is prepared for automatic hosting via **GitHub Pages**.
